Admin Login

登入星澔文創後台

後台沒有預設帳號密碼。請使用你在 Firebase Authentication 內建立的 Email/Password 管理員帳號。

帳號密碼在哪裡？
到 Firebase Console → Authentication → Sign-in method 啟用 Email/Password，接著到 Users 新增使用者。新增的 Email 和密碼就是這裡的後台登入帳密。
